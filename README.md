# What's in my wallet 👛

macOS Finder 창 느낌의 알바비 계산기 웹앱이에요.

- 알바별 시급 등록, 태그 색 자동 배정 (Red → Orange → … → Gray)
- 달력에 근무·휴게시간 기록, 다른 날짜로 복사(같은 요일 전체 선택)
- 리스트 보기 · 알바별 묶어보기 · 근무 검색
- 주휴수당 자동 계산 (월~일, 주 15시간 이상, 최대 8시간)
- 월별 정산을 이미지로 저장, 데이터는 브라우저(localStorage)에 저장

HTML / CSS / JavaScript만 사용 · GitHub Pages로 배포
